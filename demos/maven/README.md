# Spring Boot Starter Site

A clean, minimal starter website built with Spring Boot, Thymeleaf, and Maven.

## Prerequisites

- Java 17 or later
- Maven 3.9+ (or use the included Maven wrapper)

## Build

```bash
mvn clean package
```

## Run

```bash
mvn spring-boot:run
```

The application starts at [http://localhost:8080](http://localhost:8080).
